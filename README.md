# コンビニ プライチ・お得情報

セブン-イレブン・ローソン・ファミリーマートの「1個買うと1個もらえる（プライチ）」などのキャンペーン情報を、各社の公式サイトから自動取得してまとめて表示するアプリです。

- 買う商品・もらえる商品を左右2つの枠＋矢印で表示するシンプルなカード形式で一覧表示
- 店舗ごとにフィルタ可能
- **プロテイン**または**無糖飲料（お茶・水・ブラックコーヒー）**が対象商品にある場合、色分けした枠とアイコンで囲み、画面の一番上（「注目」セクション）に表示
- カードから「コンビニを探す」でGoogleマップの近隣店舗検索に直接ジャンプ
- 「今すぐ更新」ボタンで手動更新、10分ごとに自動更新
- 取得に失敗した店舗は、その旨と公式サイトへのリンクを表示
- PWA対応。スマホで「ホーム画面に追加」するとアプリのようなアイコン・全画面表示で使えます

## 友達と共有できるURLを作る（デプロイ）

このリポジトリはNext.jsアプリなので、そのままではURLがありません。無料で公開URLを作るには、GitHubアカウントで [Vercel](https://vercel.com) にサインアップし、下のボタンからインポートするのが一番簡単です（数クリックで完了、CLIやサーバー管理は不要）。

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/linj80127-del/my-first&project-name=conveni-plaichi&repository-name=conveni-plaichi)

デプロイが終わると `https://xxxxx.vercel.app` のようなURLが発行されます。そのURLを友達に送れば、友達もブラウザ（またはホーム画面に追加したアイコン）から同じ内容を見られます。ブランチを更新してGitHubにpushすると、Vercel側も自動で再デプロイされます。

### スマホでアプリのように使う

デプロイ後のURLをスマホのブラウザで開き、

- **iPhone (Safari):** 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome):** メニュー（︙）→ 「ホーム画面に追加」／「アプリをインストール」

を選ぶと、ホーム画面にアイコンが追加され、ブラウザのアドレスバーなしでアプリのように開けます。

## 構成

- `app/page.tsx` — 画面本体（カード一覧、フィルタ、更新ボタン、注目セクション）
- `app/api/promos/route.ts` — 3社分をまとめて取得するAPI（5分キャッシュ）
- `lib/scrapers/` — 店舗ごとのスクレイパー（`sevenEleven.ts` / `lawson.ts` / `familyMart.ts`）。いずれも各社公式サイトの実際のHTML構造に合わせて直接書かれた専用パーサーで、汎用抽出やフォールバックは持たない
- `lib/scrapers/generic.ts` — 文字化け検知（`looksGarbled`）などの共通ユーティリティ
- `lib/scrapers/util.ts` — HTML取得（文字コード自動判定）、日付範囲パース等
- `lib/stores.ts` — 店舗名・色・参照元URLの設定
- `lib/highlight.ts` — プロテイン／無糖飲料のキーワード判定
- `lib/format.ts` — カードに表示する発券期間の整形
- `components/PromoCard.tsx` / `components/HighlightIllustration.tsx` — カードUIと、注目カードの背景イラスト
- `app/manifest.ts` / `app/icon-192`, `app/icon-512`, `app/apple-icon.tsx` — PWA用マニフェストとアイコン

## 情報源について

各社は商品情報を配信する公開APIを提供していないため、各社公式サイトのHTMLを直接解析して情報を取得しています（`lib/stores.ts` の `sourceUrl`）。

- セブン-イレブン: `sej.co.jp/cmp/plaichi.html` の `.plaichi_box` カードを解析
- ローソン: `lawson.co.jp/recommend/sale/` の一覧から「買うと無料でもらえる」系キャンペーンの詳細ページを辿って解析
- ファミリーマート: `family.co.jp` のキャンペーン特設ページを解析

第三者ブログ等へのフォールバックや、手動で調べた「土台データ」は持っていません。公式サイトの取得に失敗した場合は、正直に「取得できませんでした」と表示し、公式サイトへのリンクを案内します（誤って解析した内容を表示するより、情報がない方がまし、という判断です）。

### 制約・注意点

1. **サイト構造が変わると取得できなくなります。** `lib/scrapers/*.ts` 内のセレクタ（`.plaichi_box` 等）を、実際のページのHTML構造（devtoolsで確認）に合わせて調整してください。
2. 各社サイトへのアクセスがブロックされる・遅い等でスクレイピングが失敗した場合、その店舗のカードは表示されず、上部にエラーメッセージと公式サイトへのリンクが出ます。

## 注目商品ハイライトについて

`lib/highlight.ts` のロジックで、商品名に「プロテイン」を含むものはアンバー、無糖のお茶・水・ブラックコーヒー関連のキーワードを含むもの（ただしゼロカロリー系飲料や、抹茶味のアイス・ゼリーなど無糖飲料そのものではない商品は除外）はティールで表示し、画面上部の「注目」セクションにまとめています。実際の商品名で漏れ・誤検出があれば、このファイルのキーワードリストを調整してください。
