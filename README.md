# コンビニ プライチ・お得情報

セブン-イレブン・ローソン・ファミリーマートの「1個買うと1個もらえる（プライチ）」などのキャンペーン情報を、各社の公式サイトから自動取得してまとめて表示するアプリです。

- 商品名、価格、キャンペーン期間をシンプルなカード形式で一覧表示
- 店舗ごとにフィルタ可能
- **プロテイン**が対象商品にある場合は赤枠、**無糖茶・水**が対象商品にある場合は青枠で囲み、画面の一番上（「注目」セクション）に表示
- 「今すぐ更新」ボタンで手動更新、10分ごとに自動更新
- 取得に失敗した店舗は、その旨と公式サイトへのリンクを表示（前回成功データがあればそれを表示）

## 使い方

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

本番用ビルド:

```bash
npm run build
npm run start
```

## 構成

- `app/page.tsx` — 画面本体（カード一覧、フィルタ、更新ボタン、注目セクション）
- `app/api/promos/route.ts` — 3社分をまとめて取得するAPI（5分キャッシュ）
- `lib/scrapers/` — 店舗ごとのスクレイパー（`sevenEleven.ts` / `lawson.ts` / `familyMart.ts`）
- `lib/scrapers/generic.ts` — 公式サイト向け（カード抽出）とブログ記事向け（見出しブロック抽出）の共通パース処理
- `lib/stores.ts` — 店舗名・色・参照元URLの設定
- `lib/highlight.ts` — プロテイン／無糖茶・水のキーワード判定

## 情報源について

各社は商品情報を配信する公開APIを提供していないため、公式サイトのHTMLを解析して情報を取得しています。

- **1次情報源:** 各社の公式キャンペーンページ（`lib/stores.ts` の `sourceUrl`）
- **2次情報源（フォールバック）:** 公式ページの取得に失敗した場合、下記の第三者ブログ記事を代わりに解析します

  | 店舗 | フォールバック元 |
  |---|---|
  | セブン-イレブン | [超得ニュース](https://superprofitnews.main.jp/archives/12839) |
  | ローソン | [超得ニュース](https://superprofitnews.main.jp/archives/19415) |
  | ファミリーマート | [超得ニュース](https://superprofitnews.main.jp/archives/20777) |

  「超得ニュース」は各社ごとの専用ページを持ち、キャンペーンの切り替わりに合わせて随時更新（火・木中心）されているサイトです。掲載内容は東京バーゲンマニア・マネーの達人（Yahoo!ニュース配信）・kojinabi.com・money-hensachi.com など複数の独立した媒体の報道内容と突き合わせて確認済みです（例: ローソンの「Lチキ購入で飲料無料」、ファミマの「ザバス ミルクプロテイン」対象商品などが複数媒体で一致）。

### 制約・注意点

1. **サイト構造が変わると取得できなくなります。** `lib/scrapers/*.ts` の `CARD_SELECTORS` / ブログ側の `BLOG_CONTENT_SELECTORS` を、実際のページのHTML構造（devtoolsで確認）に合わせて調整してください。
2. **この開発環境（サンドボックス）からは検証できませんでした。** このセッションのネットワークポリシーにより、公式サイト・上記ブログのいずれに対しても直接アクセスがブロックされていたため、実際のHTML構造を見ながらセレクタを調整することができませんでした。Vercelなどにデプロイした環境（ネットワーク制限のない環境）で実際に動かし、取得できない店舗があれば教えてください。実データを見ながらセレクタを修正します。
3. 取得に失敗しても画面が壊れないよう、店舗ごとに独立してエラーハンドリングし、失敗時は公式サイトへのリンクを表示します。

## 注目商品ハイライトについて

`lib/highlight.ts` のキーワードリストで、商品名に「プロテイン」を含むものは赤枠、無糖のお茶・水関連のキーワード（緑茶／烏龍茶／麦茶／天然水／ミネラルウォーター等）を含むものは青枠で表示し、画面上部の「注目」セクションにまとめています。実際の商品名で漏れ・誤検出があれば、このファイルのキーワードリストを調整してください。
