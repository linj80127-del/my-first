# コンビニ プライチ・お得情報

セブン-イレブン・ローソン・ファミリーマートの「1個買うと1個もらえる（プライチ）」などのキャンペーン情報を、各社の公式サイトから自動取得してまとめて表示するアプリです。

- 商品名、価格、キャンペーン期間をシンプルなカード形式で一覧表示
- 店舗ごとにフィルタ可能
- 「今すぐ更新」ボタンで手動更新、10分ごとに自動更新
- 取得に失敗した店舗は、その旨と公式サイトへのリンクを表示（前回成功データがあればそれを表示）

## 使い方

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

本番用ビルド:

```bash
npm run build
npm run start
```

## 構成

- `app/page.tsx` — 画面本体（カード一覧、フィルタ、更新ボタン）
- `app/api/promos/route.ts` — 3社分をまとめて取得するAPI（5分キャッシュ）
- `lib/scrapers/` — 店舗ごとのスクレイパー（`sevenEleven.ts` / `lawson.ts` / `familyMart.ts`）
- `lib/scrapers/generic.ts` — 共通のカード抽出・価格/期間パース処理
- `lib/stores.ts` — 店舗名・色・参照元URLの設定

## 重要な注意点（スクレイピングについて）

各社は商品情報を配信する公開APIを提供していないため、公式サイトのHTMLを解析して情報を取得しています。そのため以下の制約があります。

1. **サイト構造が変わると取得できなくなります。** `lib/scrapers/*.ts` の `CARD_SELECTORS` を、実際のページのHTML構造（devtoolsで確認）に合わせて調整してください。
2. **この開発環境（サンドボックス）からは検証できませんでした。** このセッションのネットワークポリシーにより `sej.co.jp` / `family.co.jp` / `lawson.co.jp` への直接アクセスがブロックされていたため、実際のHTML構造を見ながらセレクタを調整することができませんでした。Vercelなどにデプロイした環境（ネットワーク制限のない環境）で実際に動かし、取得できない店舗があれば教えてください。実データを見ながらセレクタを修正します。
3. 取得に失敗しても画面が壊れないよう、店舗ごとに独立してエラーハンドリングし、失敗時は公式サイトへのリンクを表示します。
